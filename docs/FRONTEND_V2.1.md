# ChurrasPlan — atualização visual do Frontend v2.1

## Alterações realizadas

- Cabeçalho da `index.html` fixo durante a rolagem.
- Navegação interna da página principal com atalhos para Início, Como funciona, Cálculo e Lista de compras.
- CTA permanente "Planejar agora" no cabeçalho.
- Identidade antiga em texto + ponto/brasa substituída pelas logos oficiais fornecidas.
- Logos preparadas em `FrontEnd/assets/` para uso web com transparência e recorte adequado.
- Nova direção visual baseada em creme, madeira, terracota, brasa e carvão.
- Tipografia alterada para Lora + Nunito Sans, com aparência mais humana e acolhedora.
- Hero da home redesenhado, com menos aparência tecnológica e mais sensação de ambiente de churrasco limpo/confortável.
- Cards, formulários, stepper, botões, tabela de resultado e lista de compras receberam novo acabamento visual.
- Responsividade revisada para desktop, tablet e celular.
- Nenhum ID de formulário ou contrato JavaScript funcional foi removido.
